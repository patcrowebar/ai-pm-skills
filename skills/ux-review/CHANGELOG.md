# Changelog

## 1.0.0 (2026-11-03)

First public release.

- UX Thesis: eight core principles and four AI-native expectations
- Seven modes: Full review, Quick review, Spec injection, Build-prompt hardening, Trade-off resolver, AI feature audit, Measurement plan
- Strong / Adequate / Gap / N/A ratings with evidence instead of a single score
- Observed / Assumed / Needs testing labels on every finding
- Data-consistency check for any screen that shows numbers
- Five-factor test for trade-offs: user goal, consequences, reversibility, user and context, evidence
- Reference products used to illustrate patterns, never as templates
- Anti-dogma guardrails
- 8 eval scenarios
